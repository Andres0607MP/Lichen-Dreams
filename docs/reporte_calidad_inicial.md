# Reporte de Error 
## Título

Las Lichenpedia creadas por un administrador no son visibles para los usuarios.

## Descripción

Al iniciar sesión con un usuario de administrador, se crea y publica una nueva Lichenpedia correctamente. El registro queda almacenado en la base de datos y aparece como publicado dentro del módulo administrativo.

Sin embargo, al iniciar sesión con un usuario normal, la Lichenpedia publicada no aparece en el listado ni puede ser visualizada por los usuarios finales.
