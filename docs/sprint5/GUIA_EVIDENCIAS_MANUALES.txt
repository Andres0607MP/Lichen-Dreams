GUÍA DE EVIDENCIAS MANUALES — SPRINT 5 · LICHEN DREAMS
========================================================
Guía auxiliar para ejecutar la aplicación Android y tomar pantallazos reales de la interfaz como evidencia de las pruebas manuales.

CÓMO USARLA:
1. Guarda cada captura en: docs/sprint5/evidencias/manuales/
2. Sigue los pasos de cada caso hasta la pantalla indicada.
3. En el momento exacto indicado, toma el pantallazo.
4. Guarda el archivo con el nombre sugerido (p. ej. M1-06_login_exitoso.png).
5. No marques un caso como Aprobado solo por tener captura: ejecútalo y verifica el resultado real.
6. Si algo no se puede ejecutar, márcalo No ejecutado y explica por qué en la observación.

NOTA: No debes inventar capturas; cada imagen debe corresponder a una pantalla realmente obtenida. Esta guía NO es un sexto entregable: es un elemento auxiliar para complementar el Entregable 3.

######################################################################
EVIDENCIAS DE TABLAS EN EXCEL (MATRIZ DEL ENTREGABLE 3)
======================================================================
La matriz de ejecución del Entregable 3 también se registra en un libro de
Excel (hojas: Resumen, Matriz de Ejecución, Evidencias y Hallazgos). Estas
tablas suelen contener textos largos dentro de las celdas, por lo que, al
preparar la evidencia en Excel Online, se debe:

* Aplicar Inicio → Ajustar texto en las celdas con textos largos, para que
  el contenido permanezca dentro de su respectiva celda y no se desborde
  hacia las celdas vecinas.
* Verificar (y capturar) que el texto completo quede visible dentro de su
  celda y que, cuando sea necesario, la altura de la fila se adapte para
  mostrar el contenido completo.
* Priorizar una presentación legible y ordenada de las tablas, evitando
  textos cortados, superpuestos o desbordados.

Como evidencia de la matriz se debe capturar una vista de cada hoja del
libro (o de la hoja más representativa) DESPUÉS de aplicar el ajuste de
texto, de forma que la tabla se vea completa y legible. Esta indicación
aplica únicamente a la presentación de las tablas en Excel; no reemplaza
la evidencia visual por pantallazo de cada caso guardada en
docs/sprint5/evidencias/manuales/.

CASO: M1-01
NOMBRE: Registro exitoso
MÓDULO: Autenticación
======================================================================

OBJETIVO:
Validar que un usuario nuevo pueda registrarse correctamente en la aplicación.

PRECONDICIONES:
* Aplicación instalada y ejecutándose.
* Backend FastAPI disponible.
* Correo de prueba no registrado previamente.

PASOS:
1. Abrir la aplicación en la pantalla de inicio/login.
2. Tocar «Crear una cuenta» (registro).
3. Completar nombre, apellido, correo y contraseña (mínimo 6 caracteres y un carácter especial); confirmar contraseña.
4. Pulsar «Crear cuenta».
5. Esperar la pantalla de confirmación de cuenta.

MOMENTO EXACTO PARA TOMAR CAPTURA:
Cuando aparezca la pantalla con el mensaje de éxito (p. ej. «¡Tu cuenta está lista!») y se muestre el código de recuperación LCHN.

CAPTURA RECOMENDADA:
La captura debe mostrar la pantalla posterior al registro con el código de recuperación visible.

NOMBRE SUGERIDO:
`M1-01_registro_exitoso.png`
